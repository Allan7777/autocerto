Antes de começar

Tenha o e-mail de leads do cliente, o CNPJ ativo da loja no Cockpit e acesso autorizado aos dois painéis. Para a rotina de Revisões, também será necessário o ID/código do cliente no AutoCerto.

FinalidadeUsuárioOnde usar
EstoqueE-mail derivado do endereço de leads, sem o trecho “leads” (ex.: loja@autocerto.com)Cockpit → Estoque terceiro; AutoCerto → Novo Integrador
Leads (API)E-mail completo de leads (ex.: loja@leads.autocerto.com)Cockpit → Usuários; AutoCerto → Integrador Lead

A credencial de estoque e o usuário de API de leads são distintos. Utilize a senha correspondente a cada finalidade, conforme o documento interno.

Parte 1 — Configurações no Cockpit (Webmotors)

1.1 Credencial de estoque terceiro

  1. Acesse Cockpit.
  2. Abra Integrações → Estoque terceiro e clique em Adicionar credencial.
  3. Selecione Integrador: Outro e informe Nome/Identificador: Autocerto.
  4. Informe o e-mail de estoque sem “leads” e a senha de estoque indicada no manual interno.
  5. Clique em Salvar.

1.2 Usuário de API para leads

  1. Abra Gestão de acessos → Usuários → Adicionar usuário.
  2. Informe Nome: Autocerto Leads e o e-mail de leads completo.
  3. Ative o perfil Integrador de API e informe a senha de API de leads indicada no manual interno.
  4. Clique em Adicionar usuário ou Salvar.

1.3 Ativar o canal de leads

  1. Abra Integrações → Integrações de leads.
  2. No bloco Webmotors, clique em Verificar integração.
  3. No card AutoCerto, clique em Ativar integração.

Parte 2 — Configurações no AutoCerto Admin

2.1 Vincular integrador de estoque

  1. Entre no AutoCerto Admin e abra Integrações → + Novo Integrador.
  2. Selecione WebMotors, informe o usuário de estoque (sem “leads”) e a senha de estoque correspondente.
  3. Confira o CNPJ dígito a dígito com o CNPJ ativo no Cockpit.
  4. Marque Ativo: SIM e clique em Salvar.

2.2 Atualizar pacote

  1. Abra a tela do integrador ou o painel de anúncios de veículos.
  2. No bloco Webmotors, clique em Atualizar pacote.

2.3 Recebimento de leads

  1. Abra o formulário Integrador Lead.
  2. Selecione WebMotors, informe o e-mail de leads completo e a senha de API de leads correspondente.
  3. Marque Ativo: SIM e clique em Salvar.

Parte 3 — Baixa de estoque e revisões

Esta rotina é posterior à conclusão da integração. Utilize-a para forçar sincronização ou realizar baixa manual de estoque, conforme a orientação interna.

  1. No AutoCerto Admin, abra Revisões → Download de estoque.
  2. Informe o ID/código do cliente.
  3. Selecione o integrador correspondente.
  4. Clique em Localizar para executar a varredura e a baixa no banco de dados.

Problemas comuns

SintomaO que verificar
Estoque não sincronizaConfirme se o e-mail de estoque está sem “leads” e se foi usada a senha de estoque, não a de API de leads.
Estoque não sincroniza mesmo com credenciais corretasConfira se o CNPJ no Cockpit e no AutoCerto é idêntico.
Leads não chegamVerifique o e-mail de leads completo, a senha de API de leads, o perfil Integrador de API e a ativação do canal no Cockpit.
Integração salva sem efeitoConfirme se o campo Ativo está em SIM.
Pacote desatualizadoRepita Atualizar pacote ou utilize a rotina de Revisões após a integração.
